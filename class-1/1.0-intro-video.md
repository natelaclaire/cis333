## Course Overview

This is a hands-on course focused on building practical PHP programming skills while also developing an understanding of core web development concepts.

In addition to PHP, we’ll occasionally work with:

* HTML
* CSS
* A small amount of JavaScript

You do not need to be an expert in those technologies before starting the course. I’ll guide you through anything you need to know as we go.

PHP is a server-side programming language, often referred to as a back-end technology. Front-end technologies like HTML, CSS, and JavaScript run in the browser, while PHP runs on the server and generates content dynamically.

PHP continues to be widely used today and powers many major platforms and frameworks, including:

* WordPress
* Drupal
* Joomla
* Magento
* Laravel
* Symfony

In this course, we’ll focus primarily on building PHP applications directly and understanding the fundamentals clearly before moving into more advanced architectures.

## Required Software and Tools

You do not need to install PHP directly on your computer for this course.

You will need:

* A modern web browser
* A free GitHub account

We will use **GitHub Codespaces**, which provides a cloud-based development environment directly in the browser.

Using Codespaces ensures that:

* Everyone uses the same PHP environment
* Your projects are easy to submit
* I can reproduce and test your work consistently

This also introduces you to workflows commonly used in professional software development.

## Academic Integrity and AI Use

I want to specifically address the use of generative AI tools such as:

* ChatGPT
* GitHub Copilot
* Microsoft Copilot
* Google Gemini

You are encouraged to use AI tools for:

* Brainstorming
* Planning
* Generating written content
* Exploring ideas

However, you may **not** use AI to generate the PHP code that you submit for assignments in this course.

The goal of the class is to help you learn how PHP works so that, in the future, you can use AI tools effectively and safely as a developer.

If you do use AI in any part of an assignment, you must include a brief disclosure explaining:

* Which tool you used
* What prompt you entered
* How you used the output

If you are unsure whether a particular use of AI is appropriate, please ask me.
