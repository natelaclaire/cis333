# 8.1 Project Setup and Reading a File

In Class 8, we start Chapter 9 by building a small file-based web app. For
this first tutorial, we are not using forms. We will read a sample note from
disk and display it in the browser.

## App Structure

We start with a small folder structure:

```text
class-8/app/
  index.php
  partials/
    header.php
    footer.php
  storage/
    notes/
      welcome.txt
```

The `storage/notes/` folder is where our note files live.

## Reading a File into a String

Chapter 9 introduces `file_get_contents()` for reading an entire file into a
string.

In `class-8/app/index.php`, we build a file path using `__DIR__` and read the
note:

```php
<?php
$noteFile = __DIR__ . '/storage/notes/welcome.txt';
$noteText = file_get_contents($noteFile);
```

`file_get_contents()` returns the file contents as a string. If it fails, it
returns `false`.

## Displaying File Contents Safely in HTML

When you print file contents into a web page, escape it so that any
characters like `<` and `>` are treated as text.

In `class-8/app/index.php`, we use `htmlspecialchars()`:

```php
<pre><?php print htmlspecialchars($noteText === false ? '' : $noteText, ENT_QUOTES, 'UTF-8'); ?></pre>
```

Next, we will improve this by confirming that files and directories exist
before reading and by creating them when appropriate.
