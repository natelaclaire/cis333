# 8.9 Safety and Path Handling

Working with files is powerful, but it also comes with security risks.
Any time a *user* can influence a filename or path, you need to defend against
path traversal (for example: `../../secret.txt`) and other mistakes that could
read or overwrite the wrong file.

In this tutorial we add a safe "view note" page that only allows reading notes
from a known directory.

## New Page: View Notes Safely

We add `class-8/app/pages/view-note.php` and link it from the homepage.

This page:

- discovers available notes using `glob()`
- builds an **allowlist** of note filenames (basenames only)
- reads a requested note only if it is in the allowlist
- escapes output before displaying it in HTML

## Never Trust User Input in File Paths

This is the unsafe idea (do not do this):

```php
<?php
$name = $_GET['note'];
$path = __DIR__ . '/../storage/notes/' . $name;
$contents = file_get_contents($path);
```

If `$name` contains `../`, the user can attempt to break out of the `notes/`
directory.

## Safer Approach 1: Allowlist of Known Filenames

Instead, build the list of allowed filenames from the directory itself.

```php
<?php
$notesDir = __DIR__ . '/../storage/notes';

$noteFiles = glob($notesDir . '/*.txt');
$noteFiles = $noteFiles === false ? [] : $noteFiles;

$allowed = array_map('basename', $noteFiles);

$requested = $_GET['note'] ?? '';
$requested = is_string($requested) ? $requested : '';
$requested = basename($requested);

if (!in_array($requested, $allowed, true)) {
    // Reject: not a known note.
}
```

Two notes:

- `basename()` strips directory parts, which helps prevent `../../` style input.
- `in_array(..., true)` uses strict comparison.

## Safer Approach 2 (Defense-in-Depth): `realpath()` Containment Check

Even with an allowlist, it is common to add a second check: resolve the path
and ensure it stays inside the intended directory.

```php
<?php
$notesDirReal = realpath($notesDir);
$candidateReal = realpath($notesDir . '/' . $requested);

if ($notesDirReal === false || $candidateReal === false) {
    // Reject: couldn't resolve.
} elseif (!str_starts_with($candidateReal, $notesDirReal . DIRECTORY_SEPARATOR)) {
    // Reject: resolved outside notes dir.
}
```

`realpath()` collapses `..` segments and follows symlinks, which makes it
useful for this containment-style check.

## Prefer `__DIR__` for Reliable Paths

In web apps, relative paths depend on the current working directory, which can
vary based on how PHP is run. Using `__DIR__` helps keep paths correct and
predictable.

## Escape File Contents Before Displaying in HTML

If you display note contents in the browser, treat it as untrusted text and
escape it:

```php
<pre><?php print htmlspecialchars($noteText, ENT_QUOTES, 'UTF-8'); ?></pre>
```

That prevents HTML or JavaScript from being interpreted by the browser.
