# 8.10 Class 8 Reinforcement Exercises

These exercises give you additional practice with the file and directory
concepts from Chapter 9 while extending our file-based notes project.

All work for these exercises is in the starter app under:

- `public/exercises/`

## Exercise 8-1: Safe Note Path (Allowlist + `realpath`)

1. Open `public/exercises/8-1-safe-note-path.php`.
2. Implement `safeNotePath()`.
3. Use an allowlist of filenames, `basename()`, and a `realpath()` containment check.
4. Run the script and confirm the output matches the expected output in the file.

## Exercise 8-2: Note Stats (`file()` + Line Processing)

1. Open `public/exercises/8-2-note-stats.php`.
2. Implement `noteStats()`.
3. Use `file(..., FILE_IGNORE_NEW_LINES)` to read lines.
4. Compute:
   - number of non-empty lines
   - first non-empty line
   - total character count
5. Run the script and confirm the output matches the expected output in the file.

## Exercise 8-3: Append Activity Log (`fopen` + `fwrite`)

1. Open `public/exercises/8-3-append-activity-log.php`.
2. Implement `appendActivity()`.
3. Append two messages to the log file using `fopen()` and `fwrite()`.
4. Run the script and confirm the output matches the expected output in the file.

## Exercise 8-4: Archive a Note (`rename` + Directory Checks)

1. Open `public/exercises/8-4-archive-note.php`.
2. Implement `archiveNote()`.
3. Ensure the archive directory exists.
4. Move the working copy into the archive directory with `rename()`.
5. Run the script and confirm the output matches the expected output in the file.

## Exercise 8-5: JSON Metadata (`json_encode` + `json_decode`)

1. Open `public/exercises/8-5-json-metadata.php`.
2. Implement:
   - `loadJsonAssoc()`
   - `saveJsonAssoc()`
3. Read JSON from disk into a PHP array, update the array, and save it back to JSON.
4. Run the script and confirm the output matches the expected output in the file.
