# 8.7 Processing Multiple Files

In this tutorial, we process multiple files in a directory. This is a common
pattern for file-based apps: list all note files, read each one, and build a
summary view.

## New Page: Multiple Files

We add `public/pages/multiple-files.php` and link it from the homepage.

## Finding Files with `glob()`

`glob()` returns an array of file paths that match a pattern.

```php
<?php
$pattern = $notesDir . '/*.txt';
$files = glob($pattern);
if ($files === false) {
    $files = [];
}
```

If no files match, it returns an empty array. If it fails, it can return
`false`, so we fall back to `[]`.

## Reading and Summarizing Each File

We'll sort and then loop through the matching files and read each one with
`file_get_contents()`. For each note, we build a small summary:

- filename (`basename()`)
- size in bytes
- first line

This is enough data to create an index page of notes without loading or
rendering everything in full:

```php
sort($files);

$summaries = [];
foreach ($files as $filePath) {
    $base = basename($filePath);

    $text = file_get_contents($filePath);
    if ($text === false) {
        $summaries[] = [
            'file' => $base,
            'size' => 0,
            'firstLine' => '(unreadable)',
        ];
        continue;
    }

    $lines = preg_split('/\\R/', trim($text)) ?: [];
    $firstLine = $lines[0] ?? '';

    $summaries[] = [
        'file' => $base,
        'size' => strlen($text),
        'firstLine' => $firstLine,
    ];
}
```
