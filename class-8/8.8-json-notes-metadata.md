# 8.8 JSON Notes Metadata

Plain text files are great for storing the *content* of a note, but sometimes
we need *structured* data too: titles, tags, timestamps, and other metadata.
JSON is a common, lightweight format for storing that kind of structure.

In this tutorial we write a PHP array to a JSON file with `json_encode()`, then
read it back with `file_get_contents()` and convert it into a PHP array with
`json_decode()`.

## Encoding PHP Data to JSON (`json_encode`)

`json_encode()` takes a PHP value (often an array) and returns a JSON string.

Two important mapping rules:

- An associative array becomes a JSON object.
- A numerically indexed array becomes a JSON array.

We use `JSON_PRETTY_PRINT` so the file is readable.

```php
$metadata = [
    'app' => 'Class 8 Notes',
    'updatedAt' => date('c'),
    'notes' => [
        [
            'filename' => 'welcome.txt',
            'title' => 'Welcome',
            'tags' => ['intro', 'files'],
        ],
        [
            'filename' => 'todo.txt',
            'title' => 'To Do',
            'tags' => ['tasks'],
        ],
    ],
];

$json = json_encode($metadata, JSON_PRETTY_PRINT);
if ($json === false) {
    // json_last_error_msg() explains what went wrong.
    $encodeError = json_last_error_msg();
}
```

## Writing a JSON File (`file_put_contents`)

`file_put_contents()` creates the file if it does not exist. In this demo we
also pass `LOCK_EX` to reduce the chance of two requests writing the file at
the same time.

```php
$bytesWritten = false;
if ($json !== false) {
    // LOCK_EX helps prevent two requests from writing at the same time.
    $bytesWritten = file_put_contents($filePath, $json . "\n", LOCK_EX);
}
```

## Reading and Decoding JSON (`file_get_contents` + `json_decode`)

`json_decode()` converts a JSON string back into PHP values.

If you pass `true` as the second argument, JSON objects decode into associative
arrays instead of `stdClass` objects (objects are a CIS 334 topic).

```php
$jsonFromFile = file_get_contents($filePath);
$jsonFromFile = $jsonFromFile === false ? '' : $jsonFromFile;

$decoded = json_decode($jsonFromFile, true);
if (!is_array($decoded)) {
    $decoded = [];
}

if (json_last_error() !== JSON_ERROR_NONE) {
    $decodeError = json_last_error_msg();
}
```

If the file is empty or contains invalid JSON, `json_decode()` will not return
the structure you expect, so it is important to check for errors (and/or
validate the decoded data).
