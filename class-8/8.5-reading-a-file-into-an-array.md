# 8.5 Reading a File into an Array

Sometimes you want to process a text file line by line. Chapter 9 introduces
the `file()` function, which reads a file into an array where each element is
one line.

## New Page: Read Lines

We add `class-8/app/pages/read-lines.php` and link it from the homepage.
This page reads `storage/notes/todo.txt`.

## Using `file()`

```php
<?php
$lines = file($filePath, FILE_IGNORE_NEW_LINES);
```

With `FILE_IGNORE_NEW_LINES`, PHP removes the trailing newline from each
line.

If the file read fails, `file()` returns `false`, so we fall back to an empty
array.

## Processing Lines

In `read-lines.php`, we trim each line and skip blanks:

```php
<?php
foreach ($lines as $line) {
    $line = trim($line);
    if ($line === '') {
        continue;
    }

    $items[] = $line;
}
```

This is a common pattern when parsing simple line-based file formats.

Next, we will look at lower-level file functions like `fopen()` and
`fwrite()` which give you more control over how you read and write.
