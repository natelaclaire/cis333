# 8.6 Using Lower-Level File Functions

So far, we have used `file_get_contents()` and `file_put_contents()`. They
are great when you want to read or write an entire file in one call.

Chapter 9 also introduces lower-level functions that give you more control
through a file handle (a pointer):

- `fopen()` to open a file
- `fwrite()` to write bytes
- `fread()` to read bytes
- `fclose()` to close the handle

## Writing with `fopen()` and `fwrite()`

```php
<?php
$handle = fopen($filePath, 'a');
fwrite($handle, 'Log entry' . PHP_EOL);
fclose($handle);
```

Using `a` means new output is appended to the end of the file.

## Reading with `fread()`

```php
<?php
$readHandle = fopen($filePath, 'r');
$contents = fread($readHandle, 4096);
fclose($readHandle);
```

This is useful when you want to read a file in chunks instead of loading the
entire file into memory at once.
