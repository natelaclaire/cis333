# 8.2 File and Directory Existence Checks

In this tutorial, we make our app more robust by confirming that files and
directories exist before we try to use them. This prevents warnings and lets
our app bootstrap its own storage when needed.

## Directory Checks: `is_dir()` and `mkdir()`

Before writing or reading a file, confirm the directory exists.

```php
<?php
if (!is_dir($notesDir)) {
    mkdir($notesDir, recursive: true);
}
```

The `recursive: true` option creates missing parent directories as well.

## File Checks: `file_exists()`, `is_file()`, and `touch()`

To check whether a file path exists at all, use `file_exists()`. To confirm
that the path is a regular file (not a directory), use `is_file()`.

`touch()` creates an empty file if it does not exist.

```php
<?php
if (!file_exists($noteFile)) {
    touch($noteFile);
}
```

## Updating Our App: Bootstrapping Storage

We added `class-8/app/lib/functions.php` with two helpers:

- `ensureDirExists($dir)`
- `ensureFileExists($filePath, $defaultContents)`

In `class-8/app/index.php`, we now:

1. Ensure `storage/notes/` exists.
2. Ensure `welcome.txt` exists (and seed it with default text if needed).
3. Only call `file_get_contents()` once we know the file exists.

## Why This Matters

When your app depends on the filesystem, you should handle these cases:

- First run: the directory/file does not exist yet.
- File deleted: someone removed it.
- Wrong path: a path points to a directory instead of a file.
