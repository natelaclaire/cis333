# 8.4 Managing Files and Directories

In this tutorial, we cover basic filesystem management operations:

- Copying files (`copy`)
- Renaming/moving files (`rename`)
- Deleting files (`unlink`)
- Removing directories (`rmdir`)

## New Page: Manage Demo

We add `public/pages/manage-demo.php` and link it from the homepage.

The page will perform a few safe actions inside `storage/notes/`:

- Copy `welcome.txt` to a temporary copy
- Rename the copy
- Delete the renamed file
- Create a temporary `tmp/` directory and remove it only if it is empty

## Copying and Renaming

```php
<?php
if (copy($source, $copy)) {
    $messages[] = 'copied welcome.txt to welcome-copy.txt';
} else {
    $messages[] = 'copy failed';
}

if (rename($copy, $renamed)) {
    $messages[] = 'renamed welcome-copy.txt to welcome-renamed.txt';
} else {
    $messages[] = 'rename failed';
}
```

`rename()` can also move a file if the new path is in a different directory.

## Deleting Files

```php
<?php
if (is_file($renamed) && unlink($renamed)) {
    $messages[] = 'deleted welcome-renamed.txt';
} else {
    $messages[] = 'delete failed (or file missing)';
}
```

Always confirm you are deleting a regular file and that the path is what you
expect.

## Removing Directories

`rmdir()` only removes empty directories. In our demo, we check the directory
is empty before removing it.

```php
$tempDir = $notesDir . '/tmp';
ensureDirExists($tempDir);
$messages[] = 'ensured tmp directory exists';

// Only remove tmp if it is empty.
// An empty directory should have only . and .. entries.
$tmpEntries = array_values(array_diff(scandir($tempDir) ?: [], ['.', '..']));
if (count($tmpEntries) === 0) {
    if (rmdir($tempDir)) {
        $messages[] = 'removed empty tmp directory';
    } else {
        $messages[] = 'rmdir failed';
    }
} else {
    $messages[] = 'tmp not empty; skipped rmdir';
}
```
