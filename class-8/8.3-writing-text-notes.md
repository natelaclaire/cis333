# 8.3 Writing Text Notes

In this tutorial, we write text files using `file_put_contents()`. This is a
simple and common way to persist data on disk.

## New Page: Write Demo

We add `class-8/app/pages/write-demo.php` and link it from the homepage.

This page writes to a file named `log.txt` inside `storage/notes/`.

## Overwrite vs Append

By default, `file_put_contents()` overwrites the entire file contents.

```php
<?php
file_put_contents($noteFile, $header);
```

To append instead, pass the `FILE_APPEND` flag:

```php
<?php
file_put_contents($noteFile, 'Event line' . PHP_EOL, FILE_APPEND);
```

## Reading Back What You Wrote

After writing, we call `file_get_contents()` to show the current file
contents on the page.

## Why This Matters

Many small apps can store data as files without needing a database. The key
is to keep file paths predictable (use `__DIR__`) and to ensure directories
exist before writing.
