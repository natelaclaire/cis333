# 5.9 Class 5 Assignments

## Exercise 5.1: Including Files

In this exercise, you will separate code into two files and use `require_once`
with `__DIR__`.

1. Open `public/exercises/5.1-includes.php`.
2. Open `public/exercises/5.1-includes-functions.php`.
3. Add the `require_once` statement in `5.1-includes.php`.
4. Implement `fullName()` in `5.1-includes-functions.php`.
5. Run the script and confirm the output matches the expected output in the
  file.

## Exercise 5.2: Optional Parameters and Named Arguments

In this exercise, you will implement a function with an optional parameter
and call it with named arguments.

1. Open `public/exercises/5.2-optional-parameters-and-named-arguments.php`.
2. Implement `buildEmail()` to build a lowercase email address.
3. Run the script and confirm the output matches the expected output in the
  file.

## Exercise 5.3: Pass-by-Reference

In this exercise, you will modify a string in place using a reference
parameter.

1. Open `public/exercises/5.3-pass-by-reference.php`.
2. Implement `normalizeWhitespace()` so it updates `$text` in place.
3. Run the script and confirm the output matches the expected output in the
  file.

## Exercise 5.4: Variable Scope and Checkout Total

In this exercise, you will practice variable scope by reading a global
variable inside a function using `global`. You will also use an `if...else`
to compute shipping.

1. Open `public/exercises/5.4-variable-scope-checkout-total.php`.
2. Implement `checkoutTotal()`, `calculateShipping()`, and `calculateTax()`
   using `global $taxRate`.
3. Run the script and confirm the output matches the expected output in the
  file.

## Exercise 5.5: Mad Libs (CLI)

In this exercise, you will build a small interactive CLI program that uses
custom functions and string building.

1. Open `public/exercises/5.5-madlibs.php`.
2. Open `public/exercises/5.5-madlibs-functions.php`.
3. Add the `require_once` statement in `5.5-madlibs.php`.
4. Implement `aOrAn()` and `buildStory()` in `5.5-madlibs-functions.php`.
