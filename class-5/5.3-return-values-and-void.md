# 5.3 Return Values and `void`

In this video, we focus on what it means for a function to return a value,
and what happens when it does not.

## Returning Values

Use `return` to send a value back to the caller.

```php
<?php
function fullName(string $first, string $last): string
{
    return $first . ' ' . $last;
}

print fullName('Ada', 'Lovelace') . PHP_EOL;
?>
```

## Functions Without Explicit Return Values

If a function does not return anything explicitly, the return value is
`null`.

```php
<?php
function logMessage(string $message): void
{
    print $message . PHP_EOL;
}

$result = logMessage('Hello');
var_dump($result); // null
?>
```

## Early Returns (Guard Clauses)

Returning early can keep conditionals shallow and avoid deep nesting.
This is often called a "guard clause" pattern. As soon as a `return` is
encountered, the function exits immediately.

```php
<?php
function formatUsername(?string $username): string
{
    if ($username === null) {
        return 'Guest';
    }

    if (strlen($username) < 3) {
        return 'Invalid';
    }

    return $username;
}

print formatUsername(null) . PHP_EOL;
print formatUsername('Al') . PHP_EOL;
print formatUsername('Ada') . PHP_EOL;
?>
```
