# 5.4 Calling Functions from Within Functions

In this video, we practice breaking a problem into smaller functions and
calling functions from other functions. This is one of the main reasons
custom functions make code easier to maintain.

## Decomposing a Task

Instead of writing one large block of code, write small helpers with clear
names.

```php
<?php
function fullName(string $first, string $last): string
{
    return $first . ' ' . $last;
}

function greet(string $first, string $last): string
{
    $name = fullName($first, $last);
    return 'Hello, ' . $name . '!';
}

print greet('Ada', 'Lovelace') . PHP_EOL;
?>
```

## Functions Returning Booleans

A function can return a boolean, which you can store, pass to another
function, or use directly in an `if`.

```php
<?php
function isAdult(int $age): bool
{
    return $age >= 18;
}

function accessMessage(int $age): string
{
    if (isAdult($age)) {
        return 'Access granted';
    }

    return 'Access denied';
}

print accessMessage(20) . PHP_EOL;
print accessMessage(16) . PHP_EOL;
?>
```
