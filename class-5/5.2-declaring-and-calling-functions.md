# 5.2 Declaring and Calling Functions

In this video, we cover the basics of custom functions: declaring them,
calling them, passing parameters, and returning values.

## Declaring a Function

Use the `function` keyword. A function can have parameters and a return type.

```php
<?php
function greet(string $name): string
{
    return 'Hello, ' . $name . '!';
}
?>
```

PSR-12 recommends that the curly brace that opens the function body should be
on its own line, and that the function body should be indented.

## Calling a Function

Call the function by name with parentheses. The return value can be stored,
passed to another function, or printed directly. Arguments are passed within
the parentheses.

```php
<?php
$message = greet('Ada');
print $message . PHP_EOL;
?>
```

## Parameters and Return Types

Type declarations make your intent clear and help PHP catch mistakes. They
are technically optional but highly recommended in modern PHP.

```php
<?php
function add(int $a, int $b): int
{
    return $a + $b;
}

$sum = add(5, 3);
print 'sum: ' . $sum . PHP_EOL;
?>
```

## Arguments vs Parameters

- Parameters are the variables defined in the function declaration (e.g. `$name`).
- Arguments are the actual values you pass to the function when calling it (e.g. `'Ada'`).

If you get the terms mixed up, don't worry about it. The important thing is to
understand the concepts of defining and using functions.
