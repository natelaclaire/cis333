# 5.6 Optional Parameters and Named Arguments

In this video, we cover optional parameters (default values) and named
arguments. These features make functions easier to call and easier to read.

## Optional Parameters (Default Values)

Optional parameters have defaults. Required parameters should come first.

```php
<?php
function greet(string $name, string $greeting = 'Hello'): string
{
    return $greeting . ', ' . $name . '!';
}

print greet('Ada') . PHP_EOL;
print greet('Ada', 'Welcome') . PHP_EOL;
?>
```

## Named Arguments

Named arguments let you pass values by parameter name instead of position.
This helps when a function has multiple optional parameters.

```php
<?php
function createUser(string $name, string $role = 'User', bool $active = true): string
{
    return 'Name: ' . $name
        . ', Role: ' . $role
        . ', Active: ' . ($active ? 'Yes' : 'No');
}

print createUser('Ada') . PHP_EOL;
print createUser(name: 'Bob', active: false) . PHP_EOL;
?>
```

## Mixing Positional and Named

You can mix positional and named arguments, but positional arguments must
come first.

```php
<?php
print createUser('Charlie', active: false) . PHP_EOL;
?>
```
