# Chapter 5 Tutorial Map (Class 5)

Chapter 5 in PHPCrashCourse introduces custom functions and a few related
topics:

- Separating code into multiple files
- Declaring and calling functions
- Return values (including functions with no explicit return value)
- Calling functions from within functions
- Parameter and return types (including multiple types)
- Optional parameters
- Pass-by-value vs. pass-by-reference

## Planned Tutorial Sequence

1. `5.1` Separating code into multiple files (`include`, `require`, `*_once`)
   - File: `class-5/5.1-separating-code-into-multiple-files.md`
2. `5.2` Declaring and calling functions (parameters and return values)
   - File: `class-5/5.2-declaring-and-calling-functions.md`
3. `5.3` Return values and `void` (implicit `null`, early `return`)
   - File: `class-5/5.3-return-values-and-void.md`
4. `5.4` Calling functions from within functions (decomposition)
   - File: `class-5/5.4-calling-functions-from-functions.md`
5. `5.5` Multiple parameter/return types (union types) and `strict_types`
   - File: `class-5/5.5-multiple-types-and-strict-types.md`
6. `5.6` Optional parameters and named arguments (defaults, ordering)
   - File: `class-5/5.6-optional-parameters-and-named-arguments.md`
7. `5.7` Pass-by-value vs. pass-by-reference (when `&` is appropriate)
   - File: `class-5/5.7-pass-by-value-vs-pass-by-reference.md`
8. `5.8` Variable scope (local vs global, `global`, `$GLOBALS`)
   - File: `class-5/5.8-variable-scope.md`
