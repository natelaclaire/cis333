# 5.7 Pass-by-Value vs. Pass-by-Reference

In this video, we compare passing arguments by value (the default) with
passing by reference using `&`. Passing by reference lets a function modify
the caller's variable.

## Pass-by-Value (Default)

When you pass by value, the function receives its own copy.

```php
<?php
function addOne(int $number): int
{
    $number++;
    return $number;
}

$value = 10;
$next = addOne($value);

print 'value: ' . $value . PHP_EOL;
print 'next: ' . $next . PHP_EOL;
?>
```

## Pass-by-Reference

When you pass by reference, the function can modify the original variable.

```php
<?php
function addOneInPlace(int &$number): void
{
    $number++;
}

$value = 10;
addOneInPlace($value);

print 'value: ' . $value . PHP_EOL;
?>
```

## When to Use Reference Parameters

Use pass-by-reference when the purpose of the function is to modify the
input variable. Otherwise, prefer returning a value. Reference parameters
can make code harder to reason about because they introduce side effects,
so use them sparingly.
