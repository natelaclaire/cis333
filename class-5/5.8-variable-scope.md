# 5.8 Variable Scope

This video covers variable scope in PHP: where variables can be read and
written, and how scope interacts with functions. Even though Chapter 5 is
about custom functions, scope shows up immediately once you start writing
your own helpers.

## Local Scope

Variables declared inside a function are local to that function.

```php
<?php
function sayHello(): void
{
    $message = 'Hello from inside the function!';
    print $message . PHP_EOL;
}

sayHello();
// print $message . PHP_EOL; // Undefined variable: $message
?>
```

## Global Scope

Variables declared outside of a function are in the global scope. They are
not automatically available inside functions.

```php
<?php
$siteName = 'MyWebsite';

function displaySite(): void
{
    // print $siteName . PHP_EOL; // Undefined variable: $siteName
}
?>
```

## The `global` Keyword

Use `global` to import a global variable into a function's local scope.

```php
<?php
$siteName = 'MyWebsite';

function displaySite(): void
{
    global $siteName;
    print 'Welcome to ' . $siteName . '!' . PHP_EOL;
}

displaySite();
?>
```

## The `$GLOBALS` Superglobal

`$GLOBALS` is an array that contains all global variables by name.

```php
<?php
$counter = 1;

function incrementCounter(): void
{
    $GLOBALS['counter']++;
}

incrementCounter();
print 'counter: ' . $counter . PHP_EOL;
?>
```

## Best Practices

- Prefer parameters and return values over globals.
- Use `global`/`$GLOBALS` sparingly; they introduce side effects.
- Use constants for values that should not change.

```php
<?php
function displaySiteName(string $name): void
{
    print 'Welcome to ' . $name . '!' . PHP_EOL;
}

displaySiteName('MyWebsite');
?>
```
