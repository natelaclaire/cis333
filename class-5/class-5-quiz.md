# Class 5 Quiz: Custom Functions

## Instructions
Choose the best answer for each question.

1. What is the main benefit of writing custom functions?
   A. They make PHP run faster automatically
   B. They allow code reuse and improve maintainability
   C. They prevent all runtime errors
   D. They eliminate the need for variables

2. Which statement best describes `require` compared to `include`?
   A. `require` continues execution if the file is missing
   B. `include` causes a fatal error if the file is missing
   C. `require` causes a fatal error if the file is missing
   D. They behave identically in all situations

3. Which statement about PHP-only included files is best practice?
   A. Always end them with `?>`
   B. Omit the closing `?>` to avoid accidental output
   C. The closing `?>` is required for `require_once`
   D. The closing `?>` enables strict types

4. What does a function return if it has no explicit `return` statement?
   A. `false`
   B. `0`
   C. `null`
   D. An empty string

5. What does a return type like `: void` indicate?
   A. The function returns a string
   B. The function returns an integer
   C. The function returns no value
   D. The function can return any type

6. What is a union type used for?
   A. Combining multiple functions into one
   B. Allowing a parameter or return value to be one of multiple types
   C. Preventing type coercion in all scripts
   D. Importing variables into function scope

7. What does `declare(strict_types=1);` do?
   A. Forces all variables to be strings
   B. Prevents function calls from returning values
   C. Disables type declarations
   D. Enforces strict type checking for scalar type declarations

8. Which statement about optional parameters is correct?
   A. Optional parameters must come before required parameters
   B. Optional parameters have default values
   C. Optional parameters can only be used with `match`
   D. Optional parameters cannot be used with type declarations

9. What are named arguments?
   A. Arguments that must be strings
   B. Arguments passed in alphabetical order
   C. Arguments passed by referencing variable names
   D. Arguments passed by parameter name instead of position

10. Which statement about variable scope is correct?
    A. Variables defined outside a function are automatically available inside it
    B. Variables defined inside a function are always global
    C. Variables defined inside a function are local to that function
    D. `global` creates a new variable unrelated to the original

## Answer Key
1. B
2. C
3. B
4. C
5. C
6. B
7. D
8. B
9. D
10. C
