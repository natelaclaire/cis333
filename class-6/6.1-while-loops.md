# 6.1 `while` Loops

Chapter 6 starts with iteration: running a block of code repeatedly while a
condition remains true. In PHP, the core idea is always the same:

- Evaluate a boolean condition
- If it is true, run the loop body
- Repeat until the condition becomes false

## Basic `while` Loop

This is the general form:

```php
<?php
while (condition) {
    // loop body
}
?>
```

You can think of a `while` loop as a gatekeeper: it checks the condition before each iteration, and only allows the loop body to run if the condition is true. You can basically use any boolean expression as the condition, but a common pattern is to use a variable that changes each time through the loop. The `while` loop is like an `if` block that iterates: `if` and `while` both check a condition, but `if` only checks it once, while `while` checks it repeatedly until it becomes false. In fact, you can change `if` to `while` in an `if` block and it will work as a loop.

A common pattern is a counter that changes each iteration:

```php
<?php
$count = 1;

while ($count <= 5) {
    print 'count: ' . $count . PHP_EOL;
    $count++;
}
?>
```

## What Makes the Loop Stop

For a `while` loop to end, something must change so the condition eventually
becomes false. If you forget to update the variable that controls the
condition, you can accidentally create an infinite loop.

```php
<?php
$count = 1;

while ($count <= 5) {
    print 'count: ' . $count . PHP_EOL;
    // Missing $count++ would cause an infinite loop.
    $count++;
}
?>
```

## Using a Flag (Boolean Variable)

When the logic is more complex than a single comparison, a boolean flag can
make the loop condition easier to read. Typically:

- Set a flag to true
- Loop while the flag is true
- Set the flag to false when it is time to stop

```php
<?php
$continueLooping = true;
$attempts = 0;

while ($continueLooping) {
    $attempts++;
    print 'attempt: ' . $attempts . PHP_EOL;

    if ($attempts >= 3) {
        $continueLooping = false;
    }
}
?>
```
