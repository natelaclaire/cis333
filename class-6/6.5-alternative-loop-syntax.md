# 6.5 Alternative Loop Syntax

PHP supports an alternative syntax for control structures that is useful in
templates where you want to mix HTML with loop blocks. Instead of curly
braces, you use `:` and a closing keyword like `endwhile;` or `endfor;`.

## `while ... endwhile`

```php
<?php
$i = 1;
?>

<ul>
<?php while ($i <= 3): ?>
    <li>Item <?php print $i; ?></li>
    <?php $i++; ?>
<?php endwhile; ?>
</ul>
```

## `for ... endfor`

```php
<ul>
<?php for ($i = 1; $i <= 3; $i++): ?>
    <li>Item <?php print $i; ?></li>
<?php endfor; ?>
</ul>
```

## When to Use It

- Use alternative syntax when writing template-style PHP files with HTML
  content inside the loop.
- Use the standard brace syntax for regular PHP scripts where the loop body
  is PHP code only.
