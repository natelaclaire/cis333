# Class 6 Quiz: Loops and Iteration

## Instructions
Choose the best answer for each question.

1. What is the primary purpose of a loop in programming?
   A. To declare variables
   B. To repeat a block of code
   C. To define a function
   D. To compare strings

2. In a `while` loop, when is the loop condition evaluated?
   A. After each iteration
   B. Before each iteration
   C. Only once at the start
   D. Only when `break` is used

3. What is the key difference between `while` and `do...while` loops?
   A. `do...while` always runs forever
   B. `do...while` checks the condition after the body executes
   C. `while` can only be used with integers
   D. `do...while` cannot use a boolean condition

4. Why is the body of a `do...while` loop guaranteed to execute at least once?
   A. The condition is optional
   B. The loop ignores the condition on the first iteration
   C. The condition is checked after the body runs
   D. PHP converts the condition to true the first time

5. What does `break` do inside a loop?
   A. Skips the rest of the current iteration
   B. Exits the loop immediately
   C. Restarts the loop from the beginning
   D. Pauses the loop until input is received

6. What does `continue` do inside a loop?
   A. Exits the loop immediately
   B. Skips the rest of the current iteration
   C. Stops the entire script
   D. Converts the loop condition to false

7. When is a `for` loop typically the best choice?
   A. When you want to repeat until a user types "quit"
   B. When you do not know how many iterations you need
   C. When you have a clear counter and a fixed number of iterations
   D. When you need to loop through an array

8. Which of the following best describes the three parts of a `for` loop?
   A. Compare, assign, print
   B. Initialize, condition, update
   C. Input, output, return
   D. Include, require, once

9. What is the main use case for alternative loop syntax like `endwhile;` and `endfor;`?
   A. It makes loops run faster
   B. It enables strict typing
   C. It is useful when mixing PHP with HTML templates
   D. It is required for `do...while`

10. Which practice best helps prevent accidental infinite loops while developing?
    A. Avoid all `for` loops
    B. Use only `do...while`
    C. Add a max-iteration guardrail or clear exit condition
    D. Always use `continue` instead of `break`

## Answer Key
1. B
2. B
3. B
4. C
5. B
6. B
7. C
8. B
9. C
10. C
