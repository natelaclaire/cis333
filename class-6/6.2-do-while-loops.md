# 6.2 `do...while` Loops

A `do...while` loop is a variation of a `while` loop where the condition is
checked after the loop body runs. The key consequence is that the loop body
is guaranteed to run at least once.

## Syntax

```php
<?php
do {
    // loop body
} while (condition);
?>
```

Notice the semicolon after the `while (condition)`.

## Guaranteed One Execution

Compare `while` and `do...while` when the condition starts out false:

```php
<?php
$count = 10;

while ($count < 5) {
    print 'while: ' . $count . PHP_EOL;
    $count++;
}

do {
    print 'do...while: ' . $count . PHP_EOL;
    $count++;
} while ($count < 5);
?>
```

In that example, the `while` loop body never runs, but the `do...while` body
runs once before checking the condition.

## A Common Pattern: Input Validation

`do...while` can be useful when you want to run the loop at least once and
keep repeating until the user enters something valid.

```php
<?php
$total = 0.0;

do {
    $input = readline('Enter a number at least 100: ');
    if ($input === false) {
        $input = '';
    }

    $total = (float) $input;
} while ($total < 100);

print 'total: ' . $total . PHP_EOL;
?>
```
