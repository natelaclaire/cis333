# 6.4 `for` Loops

Use a `for` loop when you know how many times you want to repeat a block of
code. A `for` loop is built around three parts:

- initialization (runs once at the start)
- condition (checked before each iteration)
- update (runs after each iteration)

## Syntax

```php
<?php
for (initialization; condition; update) {
    // loop body
}
?>
```

## Counting Up

```php
<?php
for ($i = 1; $i <= 5; $i++) {
    print 'i: ' . $i . PHP_EOL;
}
?>
```

## Counting Down

The update step can decrement instead of increment.

```php
<?php
for ($i = 5; $i >= 1; $i--) {
    print 'i: ' . $i . PHP_EOL;
}
?>
```

## Using `break` and `continue`

You can still use `break` to exit the loop and `continue` to skip to the next iteration.

```php
<?php
for ($i = 1; $i <= 10; $i++) {
    if ($i === 3) {
        continue;
    }

    if ($i === 8) {
        break;
    }

    print 'i: ' . $i . PHP_EOL;
}
?>
```

## When to Use `for` vs `while`

- Use `for` when you have a clear counter and fixed repetition.
- Use `while` when repetition depends on a condition that changes in a less
  predictable way (user input, flags, external state).
