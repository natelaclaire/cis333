# 6.3 `break` and `continue`

Sometimes you want more direct control over loop flow:

- `break` exits the loop immediately.
- `continue` skips the rest of the current iteration and moves to the next
  iteration.

These keywords work in `while`, `do...while`, and `for` loops.

## `break`: Stop the Loop

A common pattern is an intentional infinite loop that ends when your code
decides it is time to stop.

```php
<?php
while (true) {
    $input = readline('type something (or: quit): ');
    if ($input === false) {
        $input = '';
    }

    $input = trim($input);

    if ($input === 'quit' || $input === 'q') {
        break;
    }

    print 'you typed: ' . $input . PHP_EOL;
}

print 'done' . PHP_EOL;
?>
```

This avoids a separate boolean flag and exits immediately when the user wants
to quit.

## `continue`: Skip an Iteration

Use `continue` when you want to ignore some values but keep looping.

```php
<?php
for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 !== 0) {
        continue;
    }

    print 'even: ' . $i . PHP_EOL;
}
?>
```

In that loop, odd numbers are skipped and only even numbers are printed.

## Use Them Intentionally

`break` and `continue` are powerful, but overusing them can make loops hard
to follow. Use them when they make the loop logic simpler and clearer.
