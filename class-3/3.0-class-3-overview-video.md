Now let’s take a look at this week’s content.

We begin with a short discussion of whitespace, both inside and outside of strings, and how PHP treats whitespace differently depending on the context. 

Next, we cover string literals and escaping. This section explains the difference between single-quoted and double-quoted strings and how PHP handles them differently. 

After that, we move into concatenation and interpolation. These topics focus on combining strings together, combining variables with strings, and using escape sequences for special characters. Interpolation provides an alternative to concatenation in many situations, and you’ll see examples of both approaches throughout the videos. 

We then look at HereDoc and NowDoc syntax, which are additional ways of defining strings in PHP. These are especially useful when working with large blocks of text or code. They have some important differences and a few quirks, so we’ll spend some time exploring how and when to use them. 

Next, we discuss Unicode characters in PHP. Modern PHP supports Unicode as long as your editor and file encoding support it correctly, which ours does by default. I’ll also show you how to work with Unicode escape sequences and how Unicode characters can be typed or pasted directly into PHP code. 

From there, we move into a series of videos on string functions. The first video introduces a variety of commonly used string functions in PHP. 

We then cover `sprintf` formatting, which allows you to build formatted strings. This is something we’ll continue using throughout the semester. 

There is also another short video covering additional string functions and a few related topics that didn’t fit neatly into the earlier discussion. 

Next, we talk about multibyte string functions. Some traditional PHP string functions operate on bytes rather than characters, which becomes a problem when working with Unicode and multibyte character sets. The multibyte string extension solves those issues by properly handling character-based operations. We’ll look at several examples and discuss why this matters. 

Finally, we finish the chapter with regular expressions. This is a large and important topic. If you’ve worked with regular expressions in another language, some of the syntax may already be familiar. They are extremely powerful, but they can also be difficult to read and write at first. I’ll walk through several examples and share some resources that can help you continue exploring regular expressions on your own.
