# 10.11 Class 10 Reinforcement Exercises (Event Directory)

These reinforcement exercises are all focused on building a single project: a simple **Event Directory**.

You will practice Chapter 11 skills:

- building HTML forms (text, textarea, date, select, radio, checkbox, checkbox arrays)
- retrieving request data with `filter_input()` (via helper functions)
- PRG (Post-Redirect-Get) redirects after POST
- output escaping with `htmlspecialchars()` (via `h()`)
- reading/writing a `.json` file as your data store

## Starter Project

Starter files are in:

- `class-10/starter-files/event-directory/`

Important:

- The router is **already set up** with all exercise routes under `/ex/...`.
- Do **not** modify routing logic.

## Running Locally

From the repository root:

```bash
php -S localhost:8080 -t class-10/starter-files/event-directory/public class-10/starter-files/event-directory/public/router.php
```

Then visit:

- `http://localhost:8080/`
- `http://localhost:8080/ex/events`

## Data Storage

The app stores data in:

- `class-10/starter-files/event-directory/app/storage/data.json`

Shape:

- `events` array

## Exercise 10-1: Events List Page

Route:

- `GET /ex/events`

Edit:

- `class-10/starter-files/event-directory/app/views/pages/ex-events-index.php`

Requirements:

- Load the JSON data and list events in a table.
- Escape user-provided strings with `h()` when rendering into HTML.
- Show a helpful empty-state message when there are no events.

## Exercise 10-2: New Event Form

Route:

- `GET /ex/events/new`

Edit:

- `class-10/starter-files/event-directory/app/views/pages/ex-events-new.php`

Requirements:

- Build a form that submits via POST to `/ex/events/create`.
- Include these inputs (with correct `name` attributes):
  - text: `title`
  - textarea: `description`
  - date: `eventDate`
  - select: `category`
  - radio: `format`
  - checkbox: `featured`
  - checkbox array: `tags[]`

## Exercise 10-3: Create Event Handler (PRG)

Route:

- `POST /ex/events/create`

Edit:

- `class-10/starter-files/event-directory/app/views/pages/ex-events-create.php`

Requirements:

- Retrieve form values using helper functions (`postString()`, `postBool()`, `postArray()`).
- Append a new event to the JSON data and save it.
- Redirect (PRG) to `/ex/events?created=1` using `redirectTo('/ex/events?created=1', 303)`.

## Exercise 10-4: Edit + Update Event (Prefill + PRG)

Routes:

- `GET /ex/events/edit?id=...`
- `POST /ex/events/update`

Edit:

- `class-10/starter-files/event-directory/app/views/pages/ex-events-edit.php`
- `class-10/starter-files/event-directory/app/views/pages/ex-events-update.php`

Requirements:

- The edit page loads the event by `id` and pre-fills all form fields.
- The update handler updates the existing event and redirects (PRG) to `/ex/events?updated=1`.

## Exercise 10-5: Delete Event (POST-only + PRG)

Route:

- `POST /ex/events/delete`

Edit:

- `class-10/starter-files/event-directory/app/views/pages/ex-events-delete.php`

Requirements:

- Delete is POST-only (return 405 for non-POST).
- Remove the event from JSON.
- Redirect (PRG) to `/ex/events?deleted=1`.
