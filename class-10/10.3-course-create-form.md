# 10.3 Course Create Form

In 10.1 we focused on form basics (GET vs POST) and PRG.
In 10.2 we built a JSON persistence layer.

Now we can build our first real CRUD screen:

- Create a course using an HTML form
- Store the course in `data.json`
- Redirect back to a course list

## Inputs We Use

Chapter 11 is about forms, so we want to practice multiple input types.

In the course create form we use:

- text inputs (`code`, `title`)
- a date input (`startDate`)
- a select dropdown (`department`, `credits`)
- radio buttons (`delivery`)
- checkboxes (a single checkbox `active`, and multiple checkboxes `meetingDays[]`)

## New Pages

We add three routes:

- `GET /courses` (list courses)
- `GET /courses/new` (show form)
- `POST /courses/create` (process form)

These map to:

- `app/pages/courses-index.php`
- `app/pages/courses-new.php`
- `app/pages/courses-create.php`

## The Create Form (`/courses/new`)

The form uses `method="post"` and an action that points to the create handler.

```html
<form method="post" action="/courses/create">
    <input name="code" type="text">
    <input name="title" type="text">
    <input name="startDate" type="date">

    <select name="department">...</select>

    <input name="delivery" type="radio" value="in_person">
    <input name="delivery" type="radio" value="online">

    <input name="active" type="checkbox" value="1">

    <input name="meetingDays[]" type="checkbox" value="mon">
    <input name="meetingDays[]" type="checkbox" value="wed">
</form>
```

## Processing POST Data (`/courses/create`)

In the handler, we retrieve values with `filter_input()` (via helper functions) and write them to JSON.

Important details:

- A checkbox that is unchecked is often **missing** from the request.
- For multiple checkboxes, use `name="meetingDays[]"` so PHP receives an array.

Excerpt:

```php
<?php
// Prefer filter_input() (via helpers) instead of reading $_POST directly.
$code = trim(postString('code'));
$title = trim(postString('title'));

$active = postBool('active');
$meetingDays = postArray('meetingDays');
```

Then we load the JSON data, append a course, and save:

```php
<?php
$data = loadData();

$data['courses'][] = [
    'id' => newId('c'),
    'code' => $code,
    'title' => $title,
    // ...
];

saveData($data);
```

Finally, we redirect (PRG):

```php
<?php
header('Location: /courses?created=1', true, 303);
exit;
```
