# 10.4 Course Edit Form

In 10.3 we created courses.

In this tutorial we add the **Update** part of CRUD:

- a page that loads an existing course from `data.json`
- an edit form that is pre-filled with the current values
- a POST handler that updates the course in JSON
- a redirect back to the course list (PRG)

## New Routes

- `GET /courses/edit?id=...` (show the edit form for a specific course)
- `POST /courses/update` (process the form and update JSON)

Files:

- `app/pages/courses-edit.php`
- `app/pages/courses-update.php`

## Why We Pass an `id`

When we create a course, we assign an ID like `c_...`.

To edit an existing course, we need a way to say which course we mean.

We keep it simple:

- the edit page uses `GET` with a query string: `/courses/edit?id=c_abc123`
- the update handler uses `POST` and includes a hidden input:
  `<input type="hidden" name="id" value="c_abc123">`
- as the textbook indicates, we could also use the query string for the update handler,
  in which case we would retrieve the ID with our `getString('id')` function.

## Pre-Filling Form Fields

The main trick in an edit form is making the HTML match the stored values.

### Text and Date Inputs

Use the stored values in `value=""`:

```php
<input name="code" type="text" value="<?php print h($code); ?>">
<input name="startDate" type="date" value="<?php print h($startDate); ?>">
```

### Select Dropdowns

Mark the matching `<option>` as selected:

```php
<?php
foreach ($departments as $dept) {
    $selected = $department === $dept ? ' selected' : '';
    print '<option value="' . h($dept) . '"' . $selected . '>' . h($dept) . '</option>';
}
?>
```

### Radio Buttons

Mark the matching input as checked:

```php
<?php
$checked = $delivery === 'online' ? ' checked' : '';
print '<input name="delivery" type="radio" value="online"' . $checked . '>';
?>
```

### Checkboxes

Single checkbox (boolean):

```php
<?php $activeChecked = $active ? ' checked' : ''; ?>
<input name="active" type="checkbox" value="1"<?php print $activeChecked; ?>>
```

Multiple checkboxes (array):

```php
<?php
$checked = in_array('mon', $meetingDays, true) ? ' checked' : '';
print '<input name="meetingDays[]" type="checkbox" value="mon"' . $checked . '>';
?>
```

## Processing the Update (POST Handler)

In the update handler, we:

1. confirm the request method is POST
2. retrieve inputs with `filter_input()` (via helper functions like `postString()` and `postArray()`)
3. load `data.json`
4. find the matching course by its ID
5. replace the course data and save
6. redirect back to `/courses?updated=1` (PRG)
