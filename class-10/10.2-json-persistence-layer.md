# 10.2 JSON Persistence Layer

Our Class 10 project is a CRUD web app. That means we need a place to store
state.

For this week, we are not using a database. Instead, we will store application
data in a JSON file.

## Why JSON?

JSON is a good fit for this class because:

- it's human-readable
- PHP can encode/decode it easily
- it pairs nicely with the secure `public/` folder structure

Tradeoffs to be aware of:

- a single JSON file is not great for heavy concurrent traffic
- you need to be careful about partial writes and data corruption

For our class project, it works well.

## Read/Write Rules

When working with JSON files, we want to be disciplined:

- Always treat file reads/writes as operations that can fail.
- Always decode JSON into an associative array (`json_decode(..., true)`).
- Always write JSON using `LOCK_EX`.
- Prefer an "atomic" write (write to a temp file, then rename).

## New File: `storage.php`

We add a small persistence layer in:

- `app/lib/storage.php`

This file provides:

- `loadData()` to read and decode JSON into a PHP array
- `saveData($data)` to encode and write the array back to disk

### Data File Location

Our JSON file lives outside the web root:

- `app/storage/data.json`

Code:

```php
<?php
function dataFilePath(): string
{
    return __DIR__ . '/../storage/data.json';
}
```

## Loading JSON (`file_get_contents` + `json_decode`)

`loadData()` follows this pattern:

1. ensure the file exists
2. read the file contents
3. decode JSON
4. normalize the shape (ensure `courses` and `registrations` are arrays)

Excerpt:

```php
<?php
$json = file_get_contents($path);
if ($json === false) {
    return defaultData();
}

$decoded = json_decode($json, true);
if (!is_array($decoded)) {
    return defaultData();
}
```

## Saving JSON (Atomic Write + `LOCK_EX`)

When writing JSON, there are two common pitfalls:

- partial writes (request dies mid-write)
- two requests writing at the same time

We reduce both risks by:

- writing to a temporary file first
- using `LOCK_EX`
- renaming into place

Excerpt:

```php
<?php
$tmp = $path . '.tmp';
$bytes = file_put_contents($tmp, $json . "\n", LOCK_EX);
if ($bytes === false) {
    return false;
}

return rename($tmp, $path);
```
