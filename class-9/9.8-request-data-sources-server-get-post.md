# 9.8 Request Data Sources: $_SERVER, $_GET, $_POST

A web request contains different kinds of data:

- request metadata (method, path, headers)
- query string parameters (in the URL)
- request body data (common with forms)

In PHP, these show up in different places.

## $_SERVER: Request Metadata

`$_SERVER` contains information about the current request and server
environment.

Common keys:

- `REQUEST_METHOD` (GET, POST, ...)
- `REQUEST_URI` (path + query string)
- `QUERY_STRING`
- `CONTENT_TYPE` (often present on POST requests)
- `HTTP_USER_AGENT`

Because `$_SERVER` values come from the request, treat them as untrusted input
if you print them into HTML.

## $_GET: Query String Parameters

Query string parameters are the key/value pairs after the `?` in a URL.

Example:

- `/pages/request-sources.php?q=php`

PHP parses the query string and places the values into `$_GET`.

Important points:

- values are strings (or arrays of strings)
- values are untrusted input

## $_POST: Form Body Parameters

When a browser submits a typical HTML form with `method="post"`, the form data
is sent in the request body.

PHP parses the form body and places the values into `$_POST`.

Important points:

- values are strings (or arrays of strings)
- values are untrusted input

## New Page: Request Sources Demo

We add `app/pages/request-sources.php` and link it from the homepage.

This page includes:

- a simple GET form that writes to `$_GET`
- a simple POST form that writes to `$_POST`
- a small set of request metadata read from `$_SERVER`

Excerpt:

```php
<?php
$method = $_SERVER['REQUEST_METHOD'] ?? '';
$q = $_GET['q'] ?? '';
$message = $_POST['message'] ?? '';

$q = is_string($q) ? $q : '';
$message = is_string($message) ? $message : '';
```

## A Note About Refreshing After POST

If you refresh a page after submitting a POST form, the browser may warn about
re-submitting the form.

We covered the PRG (Post-Redirect-Get) pattern in 9.7, which is the common way
to avoid duplicate submissions.
