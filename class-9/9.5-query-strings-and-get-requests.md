# 9.5 Query Strings and GET Requests

A **query string** is the part of a URL after the `?`.

Examples:

- `/pages/query-demo.php?name=Nate&topic=http`
- `/query?name=Nate&topic=http`

Query strings are commonly used with **GET** requests.

## What GET Means (Conceptually)

A `GET` request is used to *retrieve* a resource.

In practice:

- GET requests are easy to bookmark and share (the data is in the URL).
- GET is a good fit for search, filtering, pagination, and selecting a record.
- GET is not a good place for secrets (passwords, tokens), because query strings
  can end up in browser history, logs, and screenshots.

## Query String Format

A query string is a list of key/value pairs:

- pairs are joined with `&`
- each pair uses `=`

For example:

- `?page=2&sort=name`

## URL Encoding

URLs can only safely contain certain characters. When you need to include
spaces or special characters, they must be **URL-encoded**.

PHP can do this for you:

- `urlencode()` / `rawurlencode()` for individual values
- `http_build_query()` to build a whole query string

## Reading Query Strings in PHP (`$_GET`)

When PHP receives a request with a query string, it parses the query string and
places the parameters into the `$_GET` superglobal array.

Important points:

- Values are strings (or arrays of strings).
- Values are untrusted input.
- Escape before printing into HTML.

Example:

```php
<?php
$name = $_GET['name'] ?? '';
$name = is_string($name) ? $name : '';

print htmlspecialchars($name, ENT_QUOTES, 'UTF-8');
```

## New Page: Query Demo

We add `app/pages/query-demo.php` and link it from the homepage as `/query`, which has already been defined in `public/router.php`.

This page:

- reads `name`, `topic`, and `all` from `$_GET`
- builds links using `http_build_query()`
- optionally dumps `$_GET` so you can see exactly what PHP received

Excerpt:

```php
<?php
$examples = [
    'Name + topic' => ['name' => 'Nate', 'topic' => 'http'],
    'URL encoding' => ['name' => 'Ada Lovelace', 'topic' => 'urls & encoding'],
];

foreach ($examples as $label => $params) {
    $qs = http_build_query($params);
    // query-demo.php?name=...&topic=...
}
```

## Connecting This Back to DevTools

In the Network tab (from 9.2), click the document request and look at:

- the Request URL
- the Query String Parameters section (if your browser shows it)

This makes it easy to verify that the server is receiving what you think it is.
