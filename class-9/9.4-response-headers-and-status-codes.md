# 9.4 Response Headers and Status Codes

So far we've mostly focused on the request (what the browser sends). Now we
start controlling the response (what the server sends back).

An HTTP response is made of:

- a status code (like `200` or `404`)
- response headers
- a response body (HTML, JSON, etc.)

## Status Codes with `http_response_code()`

PHP provides `http_response_code()` to set (and get) the response status code.

```php
<?php
http_response_code(404);
```

Later, you can retrieve the currently set status code:

```php
<?php
$current = http_response_code();
```

## Response Headers with `header()`

Headers are name/value pairs that describe the response.

To set a response header in PHP:

```php
<?php
header('Cache-Control: no-store');
header('X-Demo: class-9');
```

Important rule:

- You must set headers *before* PHP sends the response body.

In practice, that means you should call `header()` and `http_response_code()`
before you start printing HTML.

## Content-Type: HTML vs JSON

One of the most important response headers is `Content-Type`.

- For HTML pages, PHP (or the web server) typically sends `text/html`.
- For JSON APIs/endpoints, you should send `application/json`.

Example:

```php
<?php
header('Content-Type: application/json; charset=UTF-8');
print json_encode(['ok' => true]);
```

## New Page: Response Demo

We add `class-9/app/pages/response-demo.php` and link it from the homepage.

This page demonstrates:

- setting a status code (200/404/418/...)
- setting custom headers (`X-Class9-Demo`, `Cache-Control`)
- returning either HTML or JSON based on a query string parameter

Excerpt:

```php
<?php
http_response_code($code);
header('X-Class9-Demo: response-demo');
header('Cache-Control: no-store');

if ($format === 'json') {
    header('Content-Type: application/json; charset=UTF-8');
    print json_encode($payload, JSON_PRETTY_PRINT) . "\n";
    exit;
}
```

## Verify in DevTools

Open DevTools -> Network, click the request to `response-demo.php`, and inspect:

- Status Code (General)
- Response Headers

This is the easiest way to confirm that your PHP code is actually sending what
you think it is.
