# 9.11 Class 9 Reinforcement Exercises

These exercises give you practice with client-server communication concepts from
Chapter 10 while extending our Class 9 HTTP Playground project.

All work for these exercises is in the starter project under:

- `class-9/starter-files/http-playground/`

To run the starter project locally from the repository root:

```bash
php -S localhost:8080 -t class-9/starter-files/http-playground/public class-9/starter-files/http-playground/public/router.php
```

Then visit `http://localhost:8080/`.

## Exercise 9-1: Request Parts (`parse_url`)

1. Open `class-9/starter-files/http-playground/app/pages/9-1-request-parts.php`.
2. Implement `requestParts()`.
3. Use `parse_url(..., PHP_URL_PATH)` and `parse_url(..., PHP_URL_QUERY)`.
4. Run the script and confirm the output matches the expected output in the file.

## Exercise 9-2: Status Codes and Headers (`http_response_code`, `header`)

1. Open `class-9/starter-files/http-playground/app/pages/9-2-status-and-headers.php`.
2. Implement `applyDemoResponse()`.
3. Set the status code to 418.
4. Set the required response headers (Content-Type, X-Exercise, Cache-Control).
5. Confirm the output matches the expected output.

## Exercise 9-3: Population Data (CSV Over a Stream)

Adapted from Exercise 5-3 in `class-10/chapter-5-reinforcement-exercises.md`.

1. Open `class-9/starter-files/http-playground/app/pages/9-3-population-data.php`.
2. Complete the TODOs to:
   - open the URL-like source with `fopen()`
   - read rows with `fgetcsv()`
   - keep only the county rows
3. Store results in the `$rows` array exactly as directed.

Note: For deterministic grading, this exercise defaults to a local sample CSV
using the `file://` wrapper. You can switch it to the real remote dataset by
changing the `$source` variable.

## Exercise 9-4: Cached Population Data (Weekly Cache)

Adapted from Exercise 5-4 in `class-10/chapter-5-reinforcement-exercises.md`.

1. Open `class-9/starter-files/http-playground/app/pages/9-4-cached-population-data.php`.
2. Implement `buildCountyRows()` (you can reuse your loop from Exercise 9-3).
3. Implement caching:
   - use the cached file if it is <= 7 days old
   - otherwise regenerate and overwrite the cached file
4. Set `$sourceUsed` to `cache` or `generated` as directed.

## Exercise 9-5: AJAX + JSON Endpoint (`fetch` + `application/json`)

1. Open `class-9/starter-files/http-playground/app/pages/9-5-api-time.php`.
2. Implement the TODOs to return JSON.
3. Set Content-Type to `application/json; charset=UTF-8`.
4. Visit `http://localhost:8080/ajax` and open DevTools -> Network.
5. Confirm you see a Fetch/XHR request to `http://localhost:8080/api/time` and that the response is JSON.
