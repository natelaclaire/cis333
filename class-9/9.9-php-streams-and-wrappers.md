# 9.9 PHP Streams and Wrappers

PHP has a powerful abstraction called **streams**.

The main idea is that many different things can be read from or written to in a
similar way:

- local files
- network resources (like `https://...`)
- in-memory streams
- special I/O streams

A **stream wrapper** is what makes this possible.

## What Is a Stream Wrapper?

A stream wrapper is the part of a resource string before `://`.

Examples:

- `file://` for local filesystem paths
- `https://` for web URLs
- `php://` for special PHP I/O streams

If a wrapper is registered, many normal file functions can work with it:

- `file_get_contents()`
- `file_put_contents()`
- `fopen()` / `fread()` / `fwrite()` / `fclose()`

## Checking What Your PHP Supports

You can ask PHP which wrappers are available:

```php
<?php
$wrappers = stream_get_wrappers();
$transports = stream_get_transports();
```

You can also check an important configuration setting:

- `allow_url_fopen`

If `allow_url_fopen` is disabled, functions like
`file_get_contents('https://www.example.com/')` will not work.

```php
<?php
$value = ini_get('allow_url_fopen');
```

## Stream Contexts (Timeouts, Headers, etc.)

When you access a network URL, you should set a reasonable timeout.

PHP supports **stream contexts** for this.

```php
<?php
$context = stream_context_create([
    'http' => [
        'timeout' => 5,
        'header' => "User-Agent: CIS333-Class9\r\n",
    ],
]);

$contents = file_get_contents('https://www.example.com/', false, $context);
```

## New Page: Streams Demo

Starting in 9.8, our project uses a secure layout with a `public/` web root.

We add:

- `class-9/http-playground/app/pages/streams-demo.php`

And route it as:

- `/streams`

This page demonstrates:

- listing available wrappers (`stream_get_wrappers()`)
- fetching a remote `https://` URL using `file_get_contents()`
- fetching a remote `https://` URL using `fopen()` + `fread()`
- using a stream context to set a timeout and a User-Agent header

For safety, the demo uses an allowlist so only `example.com` is fetchable.

From the repository root:

```bash
php -S localhost:8000 -t public public/router.php
```

Then visit:

- `http://localhost:8000/streams`
