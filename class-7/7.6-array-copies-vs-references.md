# 7.6 Array Copies vs. Array References

In this tutorial, we compare copying an array to creating a reference to an
array. The difference matters because references introduce side effects.

## Copying an Array

Assigning an array to a new variable creates a copy.

```php
<?php
$clubsCopy = $clubs;
$clubsCopy[] = 'Film Club';
```

Updating the copy does not change the original array.

## Referencing an Array

Using `&` creates a reference. Both variables point to the same array.

```php
<?php
$clubsRef = &$clubs;
$clubsRef[] = 'Math Club';
```

Updating the reference changes the original.

## New Page: Copies vs. References

We add `public/pages/array-copies-vs-references.php` to show the
difference in a web page. This page snapshots the original array, then shows
how a copy and a reference behave differently when modified.

## Best Practice

Prefer copying arrays and returning new arrays from functions. Use references
only when you have a strong reason and the side effects are clearly intended.
