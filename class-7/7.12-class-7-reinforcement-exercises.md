# 7.12 Class 7 Reinforcement Exercises

These exercises give you additional practice with the array topics from
Chapters 7 and 8 while extending our Campus Club Directory project.

All work for these exercises is in the starter app under:

- `public/exercises/`

## Exercise 7-1: Categories Page (`foreach` + `implode`)

1. Open `public/exercises/7-1-categories.php`.
2. Use nested `foreach` loops to build the `$lines` array.
3. Use `implode(', ', ...)` to join club names.
4. Confirm the rendered list items match the expected output in the file.

## Exercise 7-2: Tags Helper (Safe Access)

1. Open `public/exercises/7-2-tags-helper.php`.
2. Implement `tagsStringForClubId()`.
3. Use `array_key_exists()` to safely check for the club ID.
4. Use `implode()` to join tags.
5. Run the script and confirm it prints the expected lines.

## Exercise 7-3: Upcoming Meetings (`array_filter` + `usort`)

1. Open `public/exercises/7-3-upcoming-meetings.php`.
2. Build `$meetingsFlat` using nested `foreach` loops.
3. Use `array_filter()` to keep only Mon/Tue/Wed.
4. Use `usort()` to sort by day and then time.
5. Print each meeting line exactly as shown in the expected output.
6. Update the `public/data.php` file to include all scheduled meetings based on the expected output.

## Exercise 7-4: Meeting Row Formatting (Destructuring + `vsprintf`)

1. Open `public/exercises/7-4-meeting-row-vsprintf.php`.
2. Implement `meetingRowHtml()`.
3. Use destructuring to extract day/time/location.
4. Use `vsprintf()` to format the `<li>` string.
5. Ensure HTML output matches the expected output.

## Exercise 7-5: Remove and Compare (`unset` + `array_diff`)

1. Open `public/exercises/7-5-unset-and-diff.php`.
2. Use `unset()` to remove the `games` category.
3. Combine the remaining category club IDs into `$allowedClubIds`.
4. Use `array_diff()` to find scheduled club IDs that are not allowed.
5. Sort arrays as directed so output order is stable.
6. Confirm the printed output matches the expected output.
