# 7.8 Associative Arrays and Explicit Keys

Up to now, we have mostly used list arrays (where PHP assigns sequential
integer keys). In this tutorial, we switch to *associative arrays* by
assigning keys explicitly. This is the foundation for using meaningful string
keys.

## Why Use Explicit Keys

Explicit keys let you:

- Use stable identifiers (so order changes do not break your code)
- Look up values by a meaningful key (like a club ID)
- Group related data more easily (like categories)

## Refactor: Clubs Keyed by ID

In `public/data.php`, we change from a list of club names to an
associative array keyed by a stable string ID:

```php
<?php
$clubsById = [
    'robotics' => 'Robotics Club',
    'chess' => 'Chess Club',
    'art' => 'Art Club',
    'cyber' => 'Cybersecurity Club',
];
```

Now we can access a club by its ID:

```php
<?php
print $clubsById['robotics'];
```

## Tags and Categories as String-Keyed Arrays

We also refactor tags so they are keyed by club ID:

```php
<?php
$clubTagsById = [
    'robotics' => ['technology', 'teamwork'],
];
```

And we add a category map keyed by category name:

```php
<?php
$categories = [
    'technology' => ['robotics', 'cyber'],
    'creative' => ['art'],
];
```

## What Changed in the App

Pages that used `$clubs` now use `$clubsById` (and often `array_values()` when
we need just the list of names).

For example, in `public/pages/club-codes.php`, we can loop through clubs with:

```php
<?php foreach ($clubsById as $id => $name): ?>
    <li><?php print $id . ': ' . $name; ?></li>
<?php endforeach; ?>
```

And in `public/pages/varargs-helpers.php`, we can generate the club list with:

```php<?php
print htmlList(...array_values($clubsById));
```
