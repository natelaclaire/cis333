# 7.9 Multidimensional Arrays, Destructuring, and `vsprintf()`

In this tutorial, we store meeting schedules using multidimensional arrays
and then iterate through them cleanly using destructuring. We also use
`vsprintf()` to format output when the values are already in an array.

## Multidimensional Arrays

A multidimensional array is an array where the values are themselves arrays.
In `public/data.php`, we add `$meetingsByClubId`:

```php
<?php
$meetingsByClubId = [
    'robotics' => [
        ['Mon', '3:00 PM', 'Tech Lab'],
        ['Thu', '3:00 PM', 'Tech Lab'],
    ],
];
```

Here:

- The outer keys are club IDs.
- Each outer value is a list of meetings.
- Each meeting is an inner array with a known structure: day, time, location.

## Destructuring Inner Arrays

When you know the structure of an inner array, destructuring makes the code
clear:

```php
<?php
[$day, $time, $location] = $meeting;
```

## Formatting with `vsprintf()`

When your data is already in an array, `vsprintf()` is a great fit. It
applies an `sprintf()`-style format string using an array of values.

We use it in `public/pages/schedule.php` to build each list item:

```php
<?php
return vsprintf(
    '<li><strong>%s</strong>: %s at %s (%s)</li>',
    [$clubName, $day, $time, $location]
);
```
