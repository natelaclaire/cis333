# 7.2 Updating Arrays

In this tutorial, we start *modifying* arrays. We will build a "featured"
list of clubs by appending items, appending multiple items, adding an element
at a specific key, and removing the last element.

## New Page: Featured Clubs

We add a new page at `public/pages/featured.php` and link to it from the
homepage. The page starts with an empty array and builds it up.

```php
<?php
$featuredClubs = [];
```

## Appending Elements

To append an element, use `[]`:

```php
<?php
$featuredClubs[] = $clubs[0];
$featuredClubs[] = $clubs[3];
```

This adds new values at the end of the array.

## Appending Multiple Elements

You can append multiple values at once with `array_push()`:

```php
<?php
array_push($featuredClubs, $clubs[1], $clubs[2]);
```

## Adding an Element with a Specific Key

Even though we are still working with simple integer-keyed arrays, you can
explicitly assign a key:

```php
<?php
$featuredClubs[10] = 'Film Club';
```

When you assign keys manually, you can end up with non-sequential keys.

In PHP, an array is actually an ordered map. This means it is a data type that associates values to keys, maintaining the insertion order of elements. When you append without specifying a key, PHP assigns the next available integer key. However, when you assign a value to a specific key, it does not affect the keys of other elements. This can lead to gaps in the keys if you assign a key that is not the next integer.

## Removing the Last Element

Use `array_pop()` to remove the last element in the array.

```php
<?php
$removed = array_pop($featuredClubs);
```

`array_pop()` returns the removed value, which is useful for debugging or
confirming what you removed.

At this point, our app has two pages:

- `index.php` displays the full list of clubs.
- `pages/featured.php` builds a derived list by updating arrays.
