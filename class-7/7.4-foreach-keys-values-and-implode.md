# 7.4 `foreach`, Keys/Values, and `implode()`

In this tutorial, we practice looping through arrays and building display
text from array values. We will:

- Confirm an array is a list with `array_is_list()`
- Loop with a `for` loop (index-based)
- Loop with a `foreach` loop (value-based)
- Loop with `foreach ($array as $key => $value)` to access keys and values
- Use `implode()` to join an array into a string without a trailing separator

## Associative Array for Navigation

This page defines navigation as an associative array, mapping a label to a
link:

```php
<?php
$navLinks = [
    'Home' => '../index.php',
    'Featured' => 'featured.php',
];
```

Then we loop through it with keys and values:

```php
<ul>
<?php foreach ($navLinks as $label => $href): ?>
    <li><a href="<?php print $href; ?>"><?php print $label; ?></a></li>
<?php endforeach; ?>
</ul>
```

## List Arrays: `for` vs `foreach`

When an array is a list, you can use `for` with indexes.

```php
<ul>
<?php if ($isClubsList): ?>
    <?php for ($i = 0; $i < count($clubs); $i++): ?>
        <li><?php print 'i=' . $i . ' club=' . $clubs[$i]; ?></li>
    <?php endfor; ?>
<?php endif; ?>
</ul>
```

In many cases, `foreach` is simpler:

```php
<ul>
<?php foreach ($clubs as $club): ?>
    <li><?php print $club; ?></li>
<?php endforeach; ?>
</ul>
```

## `implode()` for Tag Lists

We store tags in an associative array where the key is the club name and the
value is a list of tags:

```php
<?php
$clubTags = [
    'Robotics Club' => ['technology', 'teamwork'],
];
```

To display tags, we use `implode(', ', $tags)` which inserts the separator
between elements (not after the last one):

```php
<?php
print implode(', ', $clubTags['Robotics Club']);
```
