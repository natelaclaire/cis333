# 7.5 Functions with a Variable Number of Arguments

In this tutorial, we create a reusable helper function that accepts a
variable number of arguments (varargs). This is useful when you want to pass
"any number" of items into a function.

## New File: `lib/functions.php`

We add `public/lib/functions.php` and define a helper that renders an
HTML list from any number of strings.

```php
<?php
function htmlList(string ...$items): string
{
    $html = '<ul>' . PHP_EOL;

    foreach ($items as $item) {
        $html .= '    <li>' . htmlspecialchars($item, ENT_QUOTES, 'UTF-8') . '</li>' . PHP_EOL;
    }

    $html .= '</ul>' . PHP_EOL;
    return $html;
}
```

The `...$items` parameter means that PHP collects all remaining arguments
into the `$items` array.

## Calling a Varargs Function

You can pass individual arguments:

```php
<?php
print htmlList('Robotics Club', 'Chess Club');
```

## Using the Spread Operator with an Array

If your values are already in an array, use the spread operator (`...`) to
pass them as individual arguments.

```php
<?php
print htmlList(...$clubs);
```
