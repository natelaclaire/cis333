# 7.3 Array Info and Safe Access

In this tutorial, we look at how to retrieve information about arrays and
how to safely access array elements without triggering undefined-key
warnings.

## New Page: Array Info

We add `public/pages/array-info.php` to demonstrate common array info
functions.

## Counting Elements

Use `count()` to find how many elements are in an array:

```php
<?php
$numClubs = count($clubs);
```

## First and Last Keys

Use these helpers to find the first and last keys in an array:

```php
<?php
$firstKey = array_key_first($clubs);
$lastKey = array_key_last($clubs);
```

These are useful when you need to detect the first/last iteration or when
you need to understand what keys exist in an array.

## Avoiding Undefined-Key Warnings

If you access a key that does not exist, PHP will warn you. Instead, check
for existence first.

Two common checks are:

- `isset($array[$key])`
- `array_key_exists($key, $array)`

The important difference is that `isset` returns false when the key exists
but the value is `null`. `array_key_exists` checks only for the key.

```php
<?php
$key = 10;

if (array_key_exists($key, $clubs)) {
    print $clubs[$key];
} else {
    print '(none)';
}
```
