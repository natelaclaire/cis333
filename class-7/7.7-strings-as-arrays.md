# 7.7 Treating Strings as Arrays of Characters

As we've discussed briefly before, in PHP you can access individual characters of a string using square
brackets, similar to accessing array elements.

```php
<?php
$word = 'PHP';
print $word[0]; // P
```

This is useful for small string-processing tasks like extracting initials.

## Helper: `clubCode()`

We add a helper function in `public/lib/functions.php` that generates a
short code from a club name by taking the first character of each word.

```php
<?php
function clubCode(string $clubName): string
{
    $words = preg_split('/\\s+/', trim($clubName)) ?: [];
    $initials = '';

    foreach ($words as $word) {
        $initials .= strtoupper($word[0]);
    }

    return $initials;
}
```

The key line is `$word[0]`, which returns the first character of each word.
