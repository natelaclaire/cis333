# 7.10 Removing, Combining, and Comparing Arrays

In this tutorial, we cover a few practical array operations that come up
often in real code:

- Removing any element with `unset()`
- Combining arrays with the spread operator (`...`)
- Comparing arrays to find differences

## New Page: Operations

We add `public/pages/operations-remove-combine-compare.php`.

## Removing an Element with `unset()`

`unset()` removes a key/value pair from an array.

```php
<?php
$categoriesCopy = $categories;
unset($categoriesCopy['games']);
```

When you remove keys, be aware that keys may no longer be sequential (for
list arrays). For associative arrays, the remaining keys are unchanged.

## Combining Arrays with the Spread Operator

The spread operator (`...`) can combine arrays into a new array.

```php
<?php
$combined = [...$categories['technology'], ...$categories['creative']];
```

This is useful when building a derived list from multiple sources.

## Comparing Arrays (Differences)

`array_diff()` returns values from the first array that do not appear in the
other.

```php
<?php
$scheduledButNotAllowed = array_diff($scheduledClubIds, $allowedClubIds);
```

This is a practical way to answer questions like:

- Which IDs are scheduled but not in the allowed list?
- Which allowed IDs have no schedule yet?

and `usort()` to build more dynamic views.
