# 7.11 Callback Functions and Arrays

In this tutorial, we use callback functions with arrays. A callback is a
function that you pass as an argument to another function. PHP includes
several array functions that take callbacks.

## New Page: Callbacks

We add `public/pages/callbacks-map-filter-sort.php` to demonstrate three
common patterns.

## `array_map()`: Transform Values

`array_map()` applies a callback to each element and returns a new array. As noted in the book, you can use a named function or an anonymous function. Here we use an arrow function (a special type of anonymous function) to uppercase club names:

```php
<?php
$uppercased = array_map(
    fn(string $name): string => strtoupper($name),
    $clubNames
);
```

## `array_filter()`: Keep Only Matching Values

`array_filter()` keeps only the values where the callback returns true.

```php
<?php
$techClubs = array_filter(
    $clubsById,
    fn(string $name, string $clubId): bool => in_array($clubId, $techClubIds, true),
    ARRAY_FILTER_USE_BOTH
);
```

`ARRAY_FILTER_USE_BOTH` gives the callback both the value and the key.

## `usort()`: Sort a Derived List

`usort()` sorts an array using a comparison callback.

```php
<?php
usort(
    $meetingsFlat,
    fn(array $a, array $b): int => strcmp($a['day'] . $a['time'], $b['day'] . $b['time'])
);
```

Here the callback returns:

- A negative number if `$a` should come before `$b`.
- Zero if they are equivalent.
- A positive number if `$a` should come after `$b`.
