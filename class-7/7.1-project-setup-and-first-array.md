# 7.1 Project Setup and First Array

In Class 7, we will learn arrays by building a small PHP web app: a campus
club directory. For now, all data will be hardcoded in PHP arrays (no forms
and no user input).

## App Structure

We will start with this structure:

```text
public/
  index.php
  data.php
  partials/
    header.php
    footer.php
```

The idea is:

- `data.php` defines arrays (our temporary "database").
- `index.php` uses those arrays to render HTML.
- `partials/` holds reusable HTML pieces.

## Creating a Simple Array

In `public/data.php`, we define a simple list array of club names:

```php
<?php
$clubs = [
    'Robotics Club',
    'Chess Club',
    'Art Club',
    'Cybersecurity Club',
];
```

This is a *list* array: PHP assigns integer keys automatically starting at
0.

## Including Files

In `public/index.php`, we load the data file and then render the page.

Use `require_once` with `__DIR__` so paths are predictable:

```php
<?php
require_once __DIR__ . '/data.php';
```

## Looping Through the Array

To display each club, we loop through `$clubs` and print a `<li>` for each
value:

```php
<ul>
<?php foreach ($clubs as $club): ?>
    <li><?php print $club; ?></li>
<?php endforeach; ?>
</ul>
```

At this point, we have our first page rendering content from an array. Next,
we will start updating arrays (append, append multiple values, and remove the
last value) to create curated views like "featured clubs".
